Only a sideways flick counts: the element is given touch-action: pan-y in CSS, so the browser keeps every vertical gesture for the page's own scroll (and cancels the pointer when it takes one, which drops the gesture here), and only the sideways ones are left for this to read. {%- endcomment -%}
